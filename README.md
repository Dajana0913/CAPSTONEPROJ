# CAPSTONEPROJ
# Montgomery County Pay Equity & Tuition Assistance Analysis  
**Author**: Dajana Ramirez Andrade  
**Course**: DATA 205  

## Project Overview  
This project analyzes gender pay gaps and tuition assistance patterns in Montgomery County using:  
- Employee salaries (2024)  
- Tuition Assistance

**Key Questions**:  
1. Is there a statistically significant gender pay gap in high-disparity departments (Police, Legislative Oversight)?  
2. How does tuition assistance correlate with departmental median salaries?  

## Repository Structure  
- `CAPSTONEPROJ/data/`: Raw and processed datasets  
- `CAPSTONEPROJ/code/`: Cleaning, EDA, and analysis scripts  
- `CAPSTONEPROJ/dashboard/`: Dashboards
- `CAPSTONEPROJ/final_report/`:Final Written Report
- `CAPSTONEPROJ/presentation/`: Final Presentation

## How to Reproduce  
1. Clone this repository.  
2. Run scripts in order:  
   - `DATA205EDA&CLEANING.Rmd`  
   - `ProjectAnalysisDajanaRamirezAndrade.Rmd`  
   - `FinalProjectAnalysisDajanaRamirezAndrade.Rmd`  
3. View final report in `final_report/`.
